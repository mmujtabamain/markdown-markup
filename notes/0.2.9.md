## New
- **`minwidth`, `minheight` and `aspect`** on any widget's use (YAML, the `:::` line, or `{…}` under a block), or as a widget's own inputs of those names (its defaults). Any two fix its box before it is drawn; one alone is warned of, all three refused (`mkp.size`). The drawn size wins, bigger or smaller; `aspect` is kept where the widget is drawn, on the web and React Native.
- **`sizeDefaults(compiled)`** gives each widget's own sizes by name, once from a host's packs, for `outline(source, { sizes })`.
- A pack's externs get `size`.
## Changed
- **Breaking:** `outline(source, { sizes, prose, className })` sizes each placeholder from the props; `outline(source, sizes, { width })`, `mount()`'s `onSizes`, `mergeSizes`, `heightAt` and `PlaceSize` are removed, and `placeholder(place, defaults, className)` takes a widget's sizes.
