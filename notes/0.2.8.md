## Fixed
- **A pack's extern with a record list** (`in sections list(record section {title, open} slot)`) handed its host no records: they now arrive as plain values in `props`, and each record's content, drawn, in `records` (React, React Native) or as an element each (`mount()`).
- **An extern's second slot**, filled with `:::fill`, was dropped: it now arrives in `slots`, by name.
- **An extern's summary** now reaches its host (`summary`) and its placeholder, which shows the pack's description when the use has none.
- **The Markdown target** wrote only an extern's first slot: it now writes its summary, then its `project md` (from its inputs) if it has one, or else its slots and each record's content under the record's title.
