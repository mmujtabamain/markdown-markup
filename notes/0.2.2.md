## New
- **Lighter pages for prebuilt documents.** `mkp-runtime.js` holds the runtime alone, and the maths engine loads only when a document needs it.
- **A first paint `mount()` takes over** (`mkp build --target fragment`, then `mount(el, bundle, { hydrate: true })`).
- **Pointing inside widgets:** `@enter`, `@leave` and `@click` on canvas shapes, `@enter`/`@leave` on containers.
- **`theme`, `padx`/`pady`, `layer clip=`, `zoom minscale=`, `arrow corner=`, `slot … if=`.**
- **Migrations:** every file says which release wrote it, and `mkp migrate` brings documents, packs and bundles up to date. Packs can `deprecate` a version and say how its uses move.
## Changed
- **Breaking:** `theme` is a reserved name (`mkp migrate` renames yours); arrows touch what they join; `self=` places both ways in a grid or stack; a zoom stops shrinking at 0.6; the renderers need `mkp-runtime.js` and `mkp-shared.js` beside them.
- A dimmed stack layer no longer covers the layers after it, and a pressed canvas shape no longer gets a box drawn round it.
