## New
- **A maths engine that loads later:** pass `maths` when it arrives (or `runtime.setMaths()`); the document keeps its state and only the waiting formulas fill in. A waiting formula is marked `data-pending`.
## Changed
- **Canvases are the right size from their first frame:** a `size=fill` or `height=` canvas measures before it paints, so nothing below it jumps.
- **Canvases draw again only when what they draw changed,** and a `pixels` layer is computed again only when a value it reads changed.
## Fixed
- CI: the tests build the CLI once, so none sees it half-rebuilt (main's MKP run failed on this after 0.2.5).
