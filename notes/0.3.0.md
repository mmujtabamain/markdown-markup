## Changed
- **Breaking: MKP 0.3 is a new version of the language.** A document written for 0.2 is moved to it by `mkp migrate`, which runs 0.2.10's own compiler and the migrator first; an `mkp.toml` beside the tree then says which version it is written for.
- **One compiler.** `mkp` (the CLI, and `@mkp/cli` for build tools) is the only thing that turns MKP into the IR every target runs; a page's IR holds only what it uses.
## New
- **A checked language.** Types, contracts and the proofs they need, what a fn may change, and every rule of the spec, each held to a conformance case.
- **Two kinds of target.** A run-time target draws an IR built ahead and carries no compiler; a real-time target compiles the text where it runs (`@mkp/wasm` in a browser), for an editor or a live preview.
- **Targets for the web, React, Vue, Svelte, Solid and Angular, egui and Android's Compose**, each in both kinds, each passing the same conformance cases.
- **Packs with versions and migrations**, and `mkp migrate` to move documents and packs between them.
- **`mkp` for Linux, macOS and Windows**, installed with `@mkp/cli`; where no binary fits, `build` and `check` run the compiler as WebAssembly.
