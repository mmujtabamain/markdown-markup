## Fixed
- **`mkp migrate` keeps your form.** A file the steps (and a pack's moves) change nothing in now keeps its own text, with only its stamp new, and the run says "nothing in it changes, restamped". From 0.2.3 to 0.2.4 every file was reprinted in canonical form though nothing in it changed. A file that does change is still written in canonical form.
