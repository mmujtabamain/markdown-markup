## New
- **Nothing moves on a first visit:** `mount()` reports each widget's height (`onSizes`), the host keeps them with the document, and `mkp-outline.js` (about 3 KB gzipped) draws the next first paint from the source alone, each widget's box at its height; `mount(el, b, { places: true })` then draws the widgets into those boxes.
- **A pack's externs drawn by the host's own components**, by id: `externs` on React, `mount()`, `firstPaint()` and React Native.
## Changed
- MKP's root says its theme with `data-mkp-theme`, a name no host's own `[data-theme]` rules catch (`data-theme` set on the root is still read).
## Fixed
- A record field typed by a pack's own type takes its default (and its values in another pack's record lines) in that pack's types.
- An extern's outs (`@toggled`) now run when the host reports them.
