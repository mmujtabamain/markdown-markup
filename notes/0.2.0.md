## New
- **`mkp-dom.js`: MKP without React.** `mount(el, bundle, { theme, onSignal })` draws a document into any element in MKP's own look, with `update()`, `setBundle()` and `unmount()`. It's in the web zip with its types, `mkp-dom.d.ts`.
- **Recipes for Vue, Svelte, Solid, Angular, Astro and plain JS.** Each is a small app in `recipes/` with a component to copy. Each is tested in a browser: it draws, the app hears the document's signals, a theme change keeps the reader's place, and it unmounts cleanly. The site's Recipes page walks through them.
- **Docs and Examples on the website.** `/docs/` has new docs written for the site: getting started, writing documents, your own widgets, the base set, using MKP in an app, recipes and the CLI. They're written in MKP and compiled once to static pages, so no MKP runs to show them. The playground moved to `/examples/`, and old links open there.
## Changed
- **Fences go to Markdown first.** A fence labelled with a code language, `text` or `math` is code or maths, even when its body looks like YAML. Only a label Markdown has no meaning for names a widget. The base widget `text` is no longer written as a fence.
- HTML comments in a document draw nothing, and `$` inside code is no longer read as maths.
