## New
- **Releases.** Each merge to main publishes a version: `mkp-web-<version>.zip` (the core with its types header, the maths engine, the React renderer) and `mkp-cli.mjs`, the CLI in one file, with checksums. The web files are also on the playground's site, under `/v/<version>/`.
- **A document as a page.** `mkp build --target html` writes one offline page that draws the document. `--target html-md` writes its Markdown as a page with no script.
## Changed
- **Slots are filled only with `:::` containers.** A slot written in a block's YAML (`body:`, `more:`, a record's `slot:`) is now the error `mkp.slot-in-yaml`. Write `:::reveal … :::fill more … :::`, or `:::tabs` holding `:::tab "Title"` blocks.
## Fixed
- The play button of a stepper or timer showed no ▶ in the default look: the glyph was drawn in the button's own dark colour.
