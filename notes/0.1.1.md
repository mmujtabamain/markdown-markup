## New
- **A calmer docs page.** Two columns, the source and the result. The result switches between Preview, Markdown, IR and Problems, so one thing shows at a time. A header names the entry, with what it teaches and previous/next buttons. The examples list is titles only, and the preview's settings sit in one View menu.
- **The website.** The landing page shows a document drawn live beside its source and its Markdown, what MKP is for, how it works and how to get the latest release. The playground is now the docs, at `/docs/`, with a link back home. Links to the old playground address open in the docs.
- **A ruleset for main** in `.github/rulesets/main.json`: changes land through a pull request whose branch is up to date, with the release-notes check and the main CI job passing.
## Changed
- **The site deploys from main**, after each merge, with each version's web files at `/v/<version>/`.
- **CI only runs what matters on a branch.** The release and release-notes checks run on main and on merge requests into it, and no longer show up as skipped on every push. The CLI check now runs the release's `mkp-cli.mjs` on every example, replacing the single-executable build.
- The README lists what's coming next, starting with a renderer that needs no framework.
