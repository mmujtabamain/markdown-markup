## New
- **Pack migrations across widgets:** `migrate statuslist@1 -> rows@1` (or `ui:rows@1` from a pack it depends on), with `rename items.name -> rows.title`, `drop items.icon "why"` and `map items.state: done -> ok` for a record list's items. Every old field and value must go somewhere, and `mkp check` proves it on the old widget's fixtures.
- **A host's icons in every renderer:** `icons=` takes any component in `@mkp/react` and `@mkp/react-native`, and an SVG string or a draw function in `mount()` and `firstPaint()`. The box keeps its name, size, colour and label.
## Changed
- A breaking change to a pack's widget is a new version beside the old one, with a `migrate` block (now in the guides).
- The website's What's new tab reads each release's full changelog, with filters, a word search and live demos.
