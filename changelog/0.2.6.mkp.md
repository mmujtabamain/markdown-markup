# 0.2.6

Three things from a host's plots, and a fix to the tests behind main's red CI run after 0.2.5. Nothing written for 0.2.5 changes meaning or look.

## Breaking

- **Nothing for documents or packs.** `Canvas` in `mkp-react.js` is now a memoised component (`React.memo`), drawn the same way; code that called it as a plain function would have to render it as an element instead.

## New

- **A maths engine can arrive after the document.** A host that loads the engine lazily draws the document at once and passes `maths` to `<MkpDocument>` or `<MkpProvider>` when it has loaded (a `Runtime` you made yourself takes `runtime.setMaths(engine)`). The document keeps its state, and only the formulas without a picture change. Until then such a formula is its TeX in a `.mkp-math[data-pending]`, so a host can give it a loading look without guessing.

## Changed

- **Canvases are the right size from their first frame.** A `size=fill` canvas started as wide as its size allows (4000 px) and learned its parent's width a frame later, so a plot with `aspect=2.4` painted 1667 px tall, then shrank, and everything below it jumped. A canvas now reads its parent's width (and a `height=` canvas its own height) before the first paint; the observer still follows later changes. Measured in Chromium: one size on screen from the first frame, layout shift 0 (it was 0.0246).
- **Canvases draw again only when what they draw changed.** Every change in a widget makes a new view; a canvas now compares its node with the last one and is left as it is when nothing it draws changed, so a hover elsewhere or a var its drawing doesn't read no longer redraws thousands of points. A `pixels` layer keeps its shape, and its CPU image where there is no GPU, until a value it reads changes: a heat map with a slider is computed again only when that slider moves.

## Fixed

- **main's CI after 0.2.5.** The tests rebuilt the CLI while other tests ran it, and a half-written file runs as an empty program (one test then read nothing from it). The CLI is built once before the tests, and a release's CLI is built in a folder of its own.

## API

### Added

**JavaScript**

- `Runtime.setMaths`: `setMaths(m: MathsRenderer | undefined): void;`

### Changed

**JavaScript**

- const `Canvas`: now `export declare const Canvas: import("react").MemoExoticComponent<typeof CanvasView>;` (was `export declare function Canvas({ n }: { n: VNode; }): ReactNode;`)
- const `RELEASE`: now `export declare const RELEASE = "0.2.6";` (was `export declare const RELEASE = "0.2.5";`)

## Migration

From 0.2.5, `mkp migrate --write` changes only each file's stamp, and keeps its text as you wrote it.
