# 0.2.8

From a host's report on 0.2.7's externs: an extern whose inputs are a list of records (an accordion's sections, each with its own content) reached the host with none of them, and the Markdown left them out. Nothing written for 0.2.7 changes meaning or look.

## Breaking

- **Nothing for documents or packs.** A host's extern components get more (`slots`, `records`, `summary`); what they got before is the same.

## Fixed

- **Record lists reach the host.** With `in sections list(record section {title: text, open: bool = false} slot)`, a `:::sections` with two `:::section` inside reached the host as `props: {}`. Each extern now gets its record lists in `props` as plain values, defaults filled in (`[{ title: "First", open: true }, { title: "Second", open: false }]`), and each record's content drawn beside them: `records.sections[i]` on React and React Native, an element per record on `mount()`, which stays the same element while that record is there. A widget inside a record's content runs there as anywhere. Records given in YAML arrive the same way, as values.
- **An extern's other slots.** Only the first slot was drawn: `in footer slot`, filled with `:::fill footer`, was dropped. The others now arrive in `slots`, by name.
- **The summary.** A block's `summary:` didn't reach the host or the placeholder. It is now `summary` for the host, and the placeholder shows it, or the pack's description of the extern when the use has none.
- **Markdown.** The Markdown target wrote an extern's first slot only, and ignored its `project md`. It now writes the summary, then the `project md` evaluated with the use's inputs if there is one, or else what the extern holds: its slots, and each record's content under the record's first text field.

```js
const Sections = ({ props, records, attrs }) => (
  <div {...attrs}>
    {props.sections.map((s, i) => (
      <details key={i} open={s.open}>
        <summary>{s.title}</summary>
        {records.sections[i]}
      </details>
    ))}
  </div>
);
```

## API

### Added

**JavaScript**

- `ExternProps.slots`: `slots: Record<string, ReactNode>;`
- `ExternProps.records`: `records: Record<string, ReactNode[]>;`
- `ExternProps.summary`: `summary?: string;`
- `DomExternProps.slots`: `slots: Record<string, HTMLElement>;` (in `mkp-dom.js`, `mkp-page.js` and `mkp-react.js`)
- `DomExternProps.records`: `records: Record<string, HTMLElement[]>;` (the same)
- `DomExternProps.summary`: `summary?: string;` (the same)
- `VNode.recs`: `recs?: Record<string, VNode[][]>;`
- `VNode.summary`: `summary?: string;`
- `Runtime.externAt`: `externAt(key: string): Inst | undefined;`

### Changed

**JavaScript**

- const `RELEASE`: now `export declare const RELEASE = "0.2.8";` (was `export declare const RELEASE = "0.2.7";`)
