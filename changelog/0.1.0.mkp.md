# 0.1.0

The first release. MKP is Markdown with widgets: a document (`name.mkp.md`) is Markdown with widget blocks, and every widget is composed from a small base set, in the document itself, in a file beside it, or in a pack. One build compiles a document to a JSON IR that apps draw with their own design system, or to Markdown for readers without it.

## Breaking

- **Slots are filled only with `:::` containers.** A slot written in a block's YAML (`body:`, `more:`, a record's `slot:`) is now the error `mkp.slot-in-yaml`, because YAML can hold data but not Markdown with widgets in it. Write `:::reveal … :::fill more … :::`, or `:::tabs` holding `:::tab "Title"` blocks.

## New

- **Releases.** Each merge to main publishes a version: `mkp-web-<version>.zip` (the core with its types header, the maths engine, the React renderer) and `mkp-cli.mjs`, the CLI in one file, with checksums. Nothing to install from a registry: put the web files in one folder of your app; they import each other. The same files are served on the site under `/v/<version>/`.
- **The core, in one file.** `mkp.js` compiles and checks documents and packs (`compile()`), runs them (`Runtime`), writes their Markdown (`writeMarkdown()`), and typesets maths with its own engine, loaded only when a document shows maths. `mkp.d.ts` types all of it in one header.
- **The React renderer.** `mkp-react.js` draws a document in React 19 (`<MkpDocument>`), in MKP's own look or with your design system's components.
- **The CLI.** `mkp-cli.mjs` checks, builds, indexes, shows, formats and packs: `check`, `build`, `index`, `show`, `schema`, `fmt`, `pack` and `cases`, with errors one a line at their exact line and column.
- **A document as a page.** `mkp build --target html` writes one offline page that draws the document, with its Markdown inside for readers with scripts off. `--target html-md` writes its Markdown as a page with no script.

## Fixed

- **The play button of a stepper or timer showed no ▶ in the default look.** The glyph was drawn in the button's own dark colour; it now takes the button's text colour.
