# 0.1.1

A maintenance release: nothing in MKP itself changed. The website and the repository's rules did.

## Changed

- **The site deploys from main.** The playground and each version's web files at `/v/<version>/` are rebuilt after each merge to main, not on every branch push, so the site always shows what was released.
- **A ruleset for main.** `.github/rulesets/main.json` can be imported in the repository's settings: changes land through a pull request whose branch is up to date, with the release-notes check and the main CI job passing.

## API

No change to the API: the JavaScript exports, the language, the CLI, the IR and the web files are as they were.
