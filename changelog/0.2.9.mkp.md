# 0.2.9

0.2.7's first paint reserved each widget's box at the height `mount()` had measured on an earlier visit, so a host had to keep those heights with each document, and a document never drawn before moved once. A widget now says its size itself, as an HTML img tag's `width` and `height` do: nothing is measured or kept, and a first visit doesn't move when the sizes are given. Nothing written for 0.2.8 changes meaning or look.

## Breaking

- **The measured sizes are gone.** `mount()`'s `onSizes`, `mergeSizes`, `heightAt` and `PlaceSize` are removed, and `outline(source, sizes, { width, prose })` is now `outline(source, { sizes, prose })`, where `sizes` is each widget's own sizes by name (below). `placeholder(place, height)` is now `placeholder(place, defaults)`. A host that kept heights can drop them; no document or pack changes.

## New

- **`minwidth`, `minheight` and `aspect`.** Any widget's use takes them, written like any other input: `aspect: 16/9` in YAML, `:::card minheight=120 aspect=2`, or `{minheight=200}` under a block. `minwidth` and `minheight` are px, where the widget starts; `aspect` is width over height (`16/9` or `1.6`), exact.
  - Any two fix its box before it is drawn, so a first paint reserves it and nothing moves when it loads. One alone gives what it can (`minheight`: that height; `aspect`: that shape at the column's width) and is warned of; all three can disagree and are refused (`mkp.size`).
  - The drawn size always wins, bigger or smaller. `aspect` is kept where the widget is drawn, at every width: CSS `aspect-ratio` on the web, a `minHeight` from its width on React Native; content taller than that still shows.
  - A widget sets its own with inputs of those names (`in aspect num = 16/9`, `in minheight int = 200`), passed on as it likes (`canvas aspect=aspect`); what a use writes wins, and the widget's fill in up to two. A widget with an input of one of those names already (a canvas's `aspect`) keeps it, and it now gives its size too.
  - Left out, the widget takes its size when drawn and may move what is below it once, as an image with no size does.
- **A first paint from the source alone.** `outline(source, { sizes, prose })` reads each top-level widget's sizes from the source and gives its placeholder a width (at most the column's) and a shape, so it stays right if the page is resized before MKP loads; a widget with none gets 160 px. `sizeDefaults(compiled)` (in `mkp.js`) gives each widget's own sizes by name: make it once from your packs and ship it with your page.

```js
import { outline } from './vendor/mkp/mkp-outline.js';
el.innerHTML = outline(source, { sizes: SIZES, prose: (md) => myMarkdown(md) });
const { mount } = await import('./vendor/mkp/mkp-dom.js');
mount(el, bundle, { places: true });
```

- **An extern's size.** A host's extern component (React, `mount()`, React Native) gets `size`, and its box keeps the `aspect`.

## API

### Added

**JavaScript**

- function `sizeOf` in `mkp.js`
- function `mergeSize` in `mkp.js`
- function `sizeBox` in `mkp.js`
- function `sizeDefaults` in `mkp.js`
- const `SIZE_KEYS` in `mkp.js`
- type `SizeKey` in `mkp.js`
- interface `WidgetSize` in `mkp.js`
- interface `WidgetSize` in `mkp-outline.js`
- `Place.size`: `size: WidgetSize;` (in `mkp-outline.js` and `mkp-dom.js`)
- `OutlineOptions.sizes`: `sizes?: Record<string, WidgetSize>;` (the same)
- `DomExternProps.size`: `size?: WidgetSize;` (in `mkp-dom.js`, `mkp-page.js` and `mkp-react.js`)
- `ExternProps.size`: `size?: WidgetSize;`
- `IRMeta.minwidth`: `minwidth?: number;`
- `IRMeta.minheight`: `minheight?: number;`
- `IRMeta.aspect`: `aspect?: number;`
- `VNode.size`: `size?: WidgetSize;`
- `Sig.sizes`: `sizes?: WidgetSize;`

**IR and files**

- `node.meta.minwidth` (optional)
- `node.meta.minheight` (optional)
- `node.meta.aspect` (optional)

### Changed

**JavaScript**

- function `placeholder`: now `export declare function placeholder(p: Place, defaults?: WidgetSize, className?: string): string;` (was `export declare function placeholder(p: Place, height: number | undefined, className?: string): string;`)
- function `outline`: now `export declare function outline(source: string, opts?: OutlineOptions): string;` (was `export declare function outline(source: string, sizes: PlaceSize[] | undefined, opts: OutlineOptions): string;`)
- const `RELEASE`: now `export declare const RELEASE = "0.2.9";` (was `export declare const RELEASE = "0.2.8";`)

### Removed

**JavaScript**

- function `heightAt` (from `mkp-dom.js` and `mkp-outline.js`)
- function `mergeSizes` (the same)
- interface `PlaceSize` (the same)
- `OutlineOptions.width`
- `MountOptions.onSizes`
