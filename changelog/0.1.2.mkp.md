# 0.1.2

A new website, and calmer CI. Nothing in the language or the API changed.

## New

- **The website.** The landing page shows a document drawn live beside its source and its Markdown, what MKP is for, how it works, and how to get the latest release. The playground became the docs, at `/docs/`, with a link back home; links to the old playground address open there.
- **A calmer docs page.** Two columns, the source and the result. The result switches between Preview, Markdown, IR and Problems, so one thing shows at a time. A header names the entry, with what it teaches and previous and next buttons. The examples list is titles only, and the preview's settings sit in one View menu.

## Changed

- **CI runs once per change, and only what the change touches.** Checks run on merge requests and on main, not again on every branch push. The website's browser tests run only when something they draw from changes, with the browser cached between runs.
- **The release and release-notes checks run on main and on merge requests into it**, and no longer show as skipped on every push. The CLI check now runs the release's own `mkp-cli.mjs` on every example, in place of the single-executable build.
- The README lists what's coming next, starting with a renderer that needs no framework.

## API

No change to the API: the JavaScript exports, the language, the CLI, the IR and the web files are as they were.
