# 0.2.1

New docs on the website. Nothing in the language or the API changed.

## New

- **Docs written for the site.** `/docs/` has seven pages: getting started, writing documents, your own widgets, the base set (each widget linked to the examples), using MKP in an app, recipes for each framework, and the CLI.

## Changed

- **The docs are static pages.** They're written in MKP and compiled once with `pnpm site:docs` into plain HTML, maths as SVG, which is committed. No MKP, IR or React runs to show them, so they load at once and work without script. CI checks the pages still match their sources.
- The site no longer draws the repository's `docs/` folder. The recipes walkthrough moved into the site's Recipes page.

## API

No change to the API: the JavaScript exports, the language, the CLI, the IR and the web files are as they were.
